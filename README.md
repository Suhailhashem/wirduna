# وردنا — نسخة واجهة للتجربة

موقع عربي متجاوب، جاهز كملفات ثابتة لاستضافة GitHub Pages. **هذه نسخة محلية تجريبية وليست الخدمة العائلية المنشورة.**

## الموجود
- تسجيل عدد الأوجه، وموضع القراءة الاختياري.
- تصحيح إجمالي قراءة اليوم.
- حساب الختمة من 604 صفحات، وترحيل الزيادة إلى الختمة التالية.
- صفحة العائلة وسجل الختمات المستنتج من القراءات.
- إدارة محلية للأسماء ووقفة اليوم.
- الحفظ في localStorage على المتصفح نفسه، مع إظهار أخطاء الحفظ.

## التشغيل
شغّل من مجلد المشروع: `python -m http.server 4173 --bind 127.0.0.1` ثم افتح http://127.0.0.1:4173 . لا تفتح index.html مباشرة لأن الوحدات البرمجية تحتاج HTTP.

## النشر على GitHub Pages
ارفع ملفات هذا المجلد إلى جذر مستودع جديد، ثم Settings → Pages → Deploy from a branch → main → /(root).
على حساب GitHub Free يحتاج هذا المسار مستودعًا عامًا. لا تضع بيانات حقيقية أو روابط دخول أو أسرار في المستودع.

## المطلوب قبل استخدام العائلة
ربط قاعدة بيانات مشتركة، والتحقق من الروابط الشخصية على الخادم، وتطبيق صلاحيات القراءة والتعديل، وحماية إدارة المحتوى، وإعداد النسخ الاحتياطي والاستعادة. لا تعتمد على إخفاء عناصر الواجهة لحماية البيانات. لا تُضمّن مفتاح إدارة قاعدة البيانات في JavaScript.

لا توجد حتى الآن روابط شخصية، مصادقة، مزامنة بين الأجهزة، إشعارات أو نشر فعلي. مسح بيانات المتصفح يمسح سجلات التجربة. عرض العائلة الحالي يعرض بيانات المتصفح نفسه فقط.
