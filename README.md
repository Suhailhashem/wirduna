# وردنا

واجهة عربية للعائلة، مستضافة على GitHub Pages ومتّصلة بقاعدة Supabase.

## الاستخدام
يفتح أفراد العائلة رابط الدعوة الخاص، ويختارون أسماءهم. يتذكر المتصفح الاختيار، وتحفظ القراءات على الخادم. من صفحة الوالدة يمكن التبديل بين قراءتها وقراءة ريم وسارة. جميع حاملي رابط العائلة يستطيعون اختيار أي اسم؛ الأسماء ليست كلمات مرور.

الإدارة برابط مستقل: نشر وقفة اليوم وتنزيل نسخة JSON من البيانات. لا تشارك رابط الإدارة في جروب العائلة.

## الحفظ
- الأوجه اليومية، تاريخ الختمات، الستريك وترتيب الأسبوع (السبت–الجمعة).
- توقيت اليوم موحد على Europe/Istanbul (UTC+3).
- إعادة المحاولة تحمل رقم عملية ثابتًا لمنع التكرار بعد انقطاع الشبكة.
- تصحيح الإجمالي يتحقق من إصدار السجل لمنع الكتابة فوق تعديل أحدث.
- سجل عمليات يحتفظ بالقيم قبل التصحيح وبعده.
- الحفظ يحتاج اتصالًا؛ لا ندّعي نجاحه قبل تأكيد الخادم.
- بيانات التجربة المحلية السابقة لا تُرحّل تلقائيًا إلى بيانات العائلة الحقيقية.

## الوصول
المفتاح المنشور في backend.js هو مفتاح Supabase publishable المخصص للمتصفح. الوصول إلى الصفوف مقيد بسياسات RLS ورمز الدعوة المرسل في ترويسة خاصة. رموز الدعوة والإدارة ليست في المستودع؛ الرابط يحويها في جزء fragment ثم يحذفها التطبيق من شريط العنوان بعد تذكرها على الجهاز.

لا تضع رموز الدخول أو service_role أو كلمات مرور في GitHub. قاعدة البيانات المجانية تخضع لحدود Supabase وقد تتوقف مؤقتًا عند انخفاض النشاط. تنزيل النسخ الاحتياطية متاح للإدارة؛ لا توجد حتى الآن نسخة تلقائية خارج Supabase. يحتفظ سجل العمليات بتاريخ التغييرات، ويمكن للمشرف التقني استخدامه لاستعادة قراءة مصححة.
